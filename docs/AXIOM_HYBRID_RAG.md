# WP-10.2 · Hybrid 科研检索与可信重放

## 实验协议

Hybrid 使用原 TaskController、Pi RPC、Durable 账本和双轴评分。三条固定对照与两轮自主候选走同一操作准入、去重、结算和交付链路。开发集 nDCG@10 决定交付，平分保留更早核验的实验。

- **Sparse** 使用 WP-10.1 的分块 BM25，按文档最大块分去重。固定对照采用分块 256、重叠 0、`k1=1.2`、`b=0.75`、Top‑10。
- **Dense** 使用 BAAI BGE Small v1.5 官方 ONNX，在本地 CPU 对每条文档或查询产生 384 维单位向量。文档使用标题及摘要，查询加官方检索前缀。输入截断至 256 词元，取首词元并 L2 归一化。按精确点积降序排列，平分使用文档 ID。固定对照取 Top‑10。[官方模型卡与 MIT 许可](https://huggingface.co/BAAI/bge-small-en-v1.5)
- **Hybrid** 按 `1/(k + rank)` 融合文档级排名。分支内重复文档只保留首个名次。固定 RRF 对照用两端 Top‑30、`k=60`、最终 Top‑10。候选可以选单路或 RRF，调整获批的分块、BM25 权重、各路深度、RRF 常量和最终截断。

审批绑定开发向量清单的 SHA‑256。候选指纹绑定开发数据、模型向量缓存、检索实现和规范化配置。Pi 只暴露 inspect、baseline、candidate、finish 四个工具以及开发集汇总。留出编码、语料读取、原始查询、相关性和独立评估在宿主侧。模型推理只选择参数，索引和评分都在本地运行。

向量矩阵每行保存小端文档或查询 ID 和 384 个 float32 值。编码前核对模型和冻结数据摘要，运行和复验前核对矩阵摘要、行序与向量范数。语料编码是一次性共享成本，重启和候选切换复用同一文档向量。索引准备、查询与评分、LLM token 分列。Node 峰值 RSS 是进程累计高水位，索引大小报告的是表示字节数。

SciFact 分片和 SHA‑256 沿用 WP-10.1。宏平均包含开发 809 条、留出 300 条查询，其中 304/112 条无正例按 0 计。有正例子集分别以 505 和 188 条为分母，报告独立的 Recall@5/10、nDCG@10、MRR@10。[SciFact 数据协议](AXIOM_RAG_EXPERIMENT.md)

## 运行与复核

官方快照只需下载预算内的 ONNX 与 tokenizer 两个文件，保存为本地 `model.onnx` 和 `tokenizer.json`。下载地址使用上表 revision 和模型仓库的 `onnx/model.onnx`、`tokenizer.json` 路径。权重和向量缓存本地保存。[官方固定快照](https://huggingface.co/BAAI/bge-small-en-v1.5/tree/5c38ec7c405ec4b44b94cc5a9bb96e735b38267a)

```bash
python3 -m venv ~/.local/share/axiom-wp102-embedding
~/.local/share/axiom-wp102-embedding/bin/python -m pip install numpy==1.26.4 onnxruntime==1.22.1 tokenizers==0.21.4
~/.local/share/axiom-wp102-embedding/bin/python axiom/rag/embed.py \
  --data "$scifact" --model "$model" --out "$vectors" --split development
```

原生 Windows Pi 可用 WSL2 中的上述 Python 编码留出。将 `AXIOM_RAG_EMBED_PYTHON` 设为 WSL2 中的绝对 Python 路径，`AXIOM_RAG_EMBED_MODEL` 设为宿主可读的固定模型目录。在 Linux 上两者均使用绝对 Linux 路径。真实 Case 自动在交付后调用编码器准备留出。

```text
npm run bench:axiom -- --list
npm run bench:axiom -- --profile rag --data DATA --out OUTPUT
npm run bench:axiom -- --profile rag-hybrid --data DATA --vectors VECTORS --vector-sha DEVELOPMENT_SHA --model deepseek/deepseek-flash --out OUTPUT
npm run bench:axiom -- --verify CASE_DIR --data DATA --vectors VECTORS --sha SAVED_MANIFEST_SHA
```

复验入口绑定操作者保存的归档摘要。它重新读取原语料和固定向量，重建倒排与平面向量索引，核对全部文档排名、索引摘要、候选指纹和交付身份，随后用冻结 Qrels 重算贡献、汇总指标和双轴检查。历史延迟保留原观测，重放耗时独立。缺少审批、证据或向量缓存时，复验失败。旧 Tiny CPU 入口和评分文件身份保留，WP-10.1 的受支持归档沿用原评分及索引协议重放。

## 当前边界

本阶段的真实语义检索为本地精确向量搜索，适合 SciFact 规模。Cross-Encoder 重排由后续独立实验评估，现有 3 GiB WSL2 环境的资源设置维持原值。该协议交付检索参数、索引身份和证据，用时与胜出策略仅代表当次实验。
