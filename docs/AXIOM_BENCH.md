# WP-07.1 · AXIOM-Bench 基础评测框架

AXIOM-Bench 从两条证据链分别评估任务达成和 Harness 正确性。任务达成衡量产物与独立指标。Harness 正确性检查授权、预算、重复启动、恢复与来源。比如任务因外部请求状态未知而没有模型交付时，任务轴失败，保留预留并禁止重放仍可让机制轴通过。权重只在本轴归一化，缺失可信数据时分数为 `null`，不会用另一个轴抵消。

## 运行

```powershell
npm run build:offline
npm run check
npm run bench:axiom -- --list
npm run bench:axiom -- --profile core
npm run bench:axiom -- --case T1-DUR-02 --case T1-SEARCH-01
npm run bench:axiom -- --profile live
npm run bench:axiom -- --verify private/axiom-bench/<batch-id>/<case-id>
node --conditions=source --experimental-strip-types --test tests/axiom/bench.test.mjs
npm run test:ml
```

`core` 为缺省离线配置，`smoke` 仅运行 T1，`live` 运行真实付费模型。也可以重复传入 Case ID，`--out` 设置主机归档父目录。真实模型通过编译后的 Pi RPC 和现有 AXIOM 扩展执行。Windows 默认使用 Research-Harness 隔离配置，其他环境可通过 `AXIOM_BENCH_AGENT_DIR` 指定。运行器沿用原生 TaskSpec 审批和用量结算。Profile 只选择内置 ID，调用方不能提交评分器、阈值或故障代码。

## 用例和隔离

Case Schema v1 记录 ID、类别、版本、任务描述、能力、数据与测试资产、环境、模式、模型、批准的预算、注入点、超时、终止条件、证据清单、评分器身份、分维度权重和预期判分模式。资产身份与 Case JSON 在执行前后核对。开发与留出用例有主机标签，当前留出示例为 `T1-BUD-01`，其截止时间注入和判题条件仅由主机加载。真实模型仅经过既有的四个科研工具，任务提示、工具反馈和工作目录不提供留出答案或评分器入口。

| Case | 数据与执行方式 | 判题要点 |
| --- | --- | --- |

## 证据协议

每次用例获得独立 Run ID 和归档目录，原生训练任务也使用单独任务目录。故障适配调用现有 WP-05 Worker 同步点和 TaskController，随后从已关停任务的 Pi Durable SQLite 读取状态。真实 CPU 重新加载归档权重和候选快照，独立脚本将实测输出写到 `recheck/`。判题器将独立结果、训练记录、正式 Full 结果、权重摘要和交付清单关联。三目标用例还独立重算受支配关系，复核每个结构化证据引用指向早先已记录的实验。

- `case.json` 保存版本化用例。 `manifest.json` 保存 Case、证据、评分器、代码、输入资产身份以及 Node、Python、Pi 和可获取的 PyTorch 版本。
- `result.json` 保存两个评分轴、逐项证据引用、运行状态、失败原因、独立指标和用量。 `report.md` 展示同一结果。
- `observed.json`、`*/ledger.json`、`*/events.jsonl` 和归档 Worker 命令保存收集证据。模型归档仅保留工具名和用量事件。子进程耗时不是 CPU 时间，估算费用也不等于供应商账单。
- `--verify` 核对当前资产身份和归档摘要，再重算两个评分轴并比对原结果。评分文件、Case 规则或证据被改动会被拒绝。超时和中断保存真实状态，证据不足时逐轴标为 unknown。

## 范围与 WP-07.2 接口

本版本为 Windows 单机 Tiny CPU 验收。合成用例、固定候选 CPU 和真实自主执行分别报告。留出示例是仓库内主机资产，适用于现有受限工具路径，公开仓库不构成面向任意代码执行器的秘密留出平台。摘要用于识别改动，主机和保存的清单是信任根。依赖资产内容发生变化时，可使用原版本复核归档。

WP-07.2 可以按 `case_id`、`case_version`、`split`、`mode`、`run_id` 和证据摘要登记多次运行。两个轴的逐项结果和失败原因可用于分组对照和后续归因。本期没有大样本 pass@k/pass^k、全规模 B0/B1/AXIOM 对照或自动更新评分器。
